# Comprendre et présenter ONMT AI

Ce dossier explique le projet en français. Il complète les anciens guides Salma sans les effacer. Les données sont synthétiques ; les QVD, calculs et modèles locaux peuvent, eux, être réellement exécutés.

**Périmètre confirmé le 14 novembre 2026 : les QVD synthétiques sont définitifs pour le rendu.** Aucun dataset réel n'est attendu. Les possibilités de configuration restent ouvertes ; les écarts fonctionnels ne sont pas supprimés. Voir le [périmètre et le reste à développer](10-perimetre-pedagogique.md).
